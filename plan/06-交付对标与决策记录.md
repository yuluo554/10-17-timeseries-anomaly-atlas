## 2. 边界与非目标（题面 §8 逐条承接）

- 只承诺 M1–M5；扩展项（token replay 式流程分析 / 实时流式 / 深度学习检测器）**只进 roadmap 不计交付物，也不留半成品接口**以免被误认为已支持。
- 不做通用图表选型/美化：图形只服务异常语义（异常带、缺口纹理、峰值、Episode 卡片、small multiples、密度热条）。
- 不做流程挖掘/决策树；不做常驻服务、不做推送告警。
- 隐私红线：数据纯本地处理、零上传；HTML 零外部请求；文档明示"用户须自行确认数据可被处理"。
- 品牌隔离：不冒用 pyod / darts / PyPOTS 等商标；比较性表述仅作事实引用；仓库名与 Skill 名不含第三方品牌词。
- 首期交付形态 = 源码包（clone 即用）+ 单文件 HTML 产物；不承诺 wheel/exe 安装面（README「已知环境问题」写明）。

## 3. 决策记录（D1–D5 见 `plan/00`；本表自 D6 起）

| 编号 | 日期 | 决策 | 弃选项与理由 |

| D6 | 2026-10-17 | **纯标准库零依赖**，不引入 numpy（**细化 plan/00 D3 的"纯标准库 + numpy"措辞**） | numpy 的 `mean/sum/dot/median` 归约顺序是实现细节（分块求和跨版本可变），而本题护城河要求 Python 与 JS 逐位复算同一结果；零依赖另让 clone 即用与 CI 首推即绿更稳。题面 M2 允许 numpy 但未要求 |
| D7 | 2026-10-17 | **规范 JSON 只含整数与字符串**：浮点在哈希边界做整数定点化（半偶舍入，`quant_decimals=6`），十进制展示串由整数构造 | 直接落浮点字面量：CPython `repr` 与 JS `Number#toString` 的最短往返表示在极端情形不保证同串；定点整数同时吸收 1-ulp 级跨语言残差 |
| D8 | 2026-10-17 | **退出码契约 0/1/2/3/4**（3 = 阶段未就绪，骨架期占位；4 = 环境前提不满足） | 把"缺 Node"混入 2（调用方给错了）会让用户分不清"我输错了"与"我环境缺东西"；把 3 复用于"缺依赖"会让"阶段未就绪"的退役流程失去单一语义 |
| D9 | 2026-10-17 | **跨语言可镜像纪律**：检测/规范化路径禁用一切超越函数（`exp/log/pow/sin/cos/sqrt`）与库归约函数，幂次展开为乘法；只允许 IEEE-754 基本运算 | 超越函数由各语言 libm 实现、结果不保证逐位相同（可差 1 ulp）→ 浏览器复算会随机 MISMATCH。这是本题复算门禁能否成立的前提条件，非优化偏好 |
| D10 | 2026-10-17 | `max_gap_ms`（时间域，整数毫秒）作为 Episode 合并口径，而非点数间隔 | 点数间隔会**跨数据缺口合并**两段本不相邻的异常（语义错误）；时间域天然不跨缺口，且与采样节奏解耦 |
| D11 | 2026-10-17 | 时间口径 = **UTC 整数 epoch 毫秒** + 手写 civil↔epoch 整数算法；落盘 ISO 定点串由整数派生；手写算法必须被 `datetime` 交叉断言证伪过一次 | `datetime.fromisoformat` 无法被 JS 镜像同等复刻（本地时区/夏令时库参与）；依赖本地时区库则复算结果随机器变 |
| D12 | 2026-10-17 | Episode 严重度排序键全部用**定点整数/字符串**（`peak_score_q` → `duration_ms` → `start_row` → `detector`）；`episode_id = "<series_id>-E<NNN>"` | 用原始浮点排序：跨语言在近并列处可能给出不同序，进而 id 与哈希全变；全局编号（不带 series）会在增删 series 时让无关 id 漂移 |
| D13 | 2026-10-17 | STL 自实现（经典 LOESS：bisquare 权重 `(1−w²)²`、内/外循环次数进 run-spec）；`period_points` 由 ACF 估计或用户声明，**生效值写入 run.json**，复算消费生效值不重跑估计 | 依赖 statsmodels（D3 已弃）；复算侧重跑 ACF 估计会把"估计器实现差异"引入哈希 |
| D14 | 2026-10-17 | 骨架期**不产桩**：未落地模块不建文件（或以 docstring-only 模块声明计划），"尚未实现"一律由 CLI exit 3 表达 | `NotImplementedError` / `return 0` / `return True` 三类桩都不会让任何门变红（方法论「桩哨兵串」族），会静默混过里程碑 |
| D15 | 2026-10-17 | 渲染用**手写 SVG**（非 canvas）、`string.Template`（非模板引擎） | canvas 不可打印、位图不可文本核验；模板引擎引入依赖 |
| D16 | 2026-10-17 | 合成场景定稿为**"冷链仓储温控与能耗监测（虚构）"**，`series_id` ∈ 温度/湿度/能耗三指标（支撑 small multiples） | 单指标场景会让 small multiples 与多指标剖面在首期无实测样本 |
