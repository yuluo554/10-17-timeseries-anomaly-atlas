## 诚实口径

- 无远端期间，一切 CI 类 DoD 写"**本地等价校验**（未接远端，CI 待首推验证）"并列**可指认的替代证据**（双解释器 pytest 全量 / 生成器 `--check` 位级一致 / selftest / 双跑一致）；首推后据实补记 run id，**历史措辞保留不改、补记是追加事实**。
- 每里程碑收尾顺序固定：DoD 验证 → plan/00·05·06 状态回写 → 写 `plan/HANDOFF-M<next>.md`（六节齐，库内相对路径）→ commit →（有远端则 push 等 CI 绿）。
- 收尾期扫哨兵串（`NotImplementedError` / `TODO: 实现` / `placeholder`）防桩混过里程碑；骨架期**不产桩**（以 exit 3 表达未就绪）。
- 状态列在里程碑完成时回填**实测证据**；未完成不预填日期或数字。
