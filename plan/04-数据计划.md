# plan/04 数据计划

## 数据来源

- **无外部数据依赖**（题面边界）：不下载、不引用任何真实业务时序；一切开发验证数据为程序化合成（纪律见 `data/README.md` §3）。
- 用户自备 CSV（时间戳列 + 数值列，可选 `series_id`）由用户提供，本 skill 只消费不产生；隐私红线 = 纯本地零上传、HTML 零外部请求。

## 合成数据资产（M1 冻结入 `data/`）

| 资产 | 生成方式 | 纪律 |
| --- | --- | --- |
| `data/synthetic/series.csv` | `tools/gen_synthetic_series.py`（splitmix64 固定 seed） | 场景"冷链仓储温控与能耗监测（虚构）"；长表 `timestamp,series_id,value`；含已知缺口行、缺失（空值）行、零值段；**禁手改** |
| `data/synthetic/manifest.json` | 同生成器实算 | 生成参数（seed/周期/趋势/噪声/植入段清单）+ 逐文件 sha256 台账；台账是生成物非手编文档 |
| `data/truth/truth.json` | 同生成器程序化派生 | **只存输入与期望**（series/类型/起止行号/植入幅度）；禁 `observed` 字段；禁手抄数字 |
| `data/truth/hash.txt` | 同生成器按 K3 规范 JSON 计算 | 真值异常集 sha256，与检测内核输出对账 |
| `data/samples/minimal.csv` | 手写最小示例（≤20 行，含 1 段缺口 + 1 个缺失值） | 供用户快速试跑；规模小到可人眼核对 |

## 真值口径（可复算性）

- 真值是**生成器的输出**，不是事后人工标注：植入段的起止行号、类型、幅度在生成时同步导出。
- 真值只登记"输入与期望"：不写"检测器观测到了什么"（禁 `observed`），观测由检测内核运行时实算——否则基准会退化成"比对两份预先算好的答案"。
- 对账单元必须**自带结论**：真值条目的键名（如 `type: "level_shift"`、`series_id`）本身就是结论，`status` 类哑值字段一律不写（"恒为哑值的键名自带结论"是基准假绿来源之一）。
- 期望值可由输入独立复算：任取一段真值，检测内核应独立得出同一组起止行号（M2 逐段全量对账，非抽样）。

## 冻结与再生成

- M1 冻结后 `data/synthetic/` 与 `data/truth/` 视为只读资产；改动必须走生成器 + `--check` 位级一致守门（**两层**：冻结产物形态断言 + 重生成逐字节比对）。
- 埋点非平凡性（生成器内显式设计，避免"真值平凡到随便都过"）：
  - 四类异常各 ≥2 段；至少 1 段落在滚动窗口边界；
  - 至少一组相邻异常段间隔**略大于**与**略小于** `max_gap_ms`（覆盖合并口径两侧——只测一侧的基准对合并逻辑没有区分度）；
  - 至少 1 个重复时间戳样本与 1 个时间戳并列样本（覆盖 tie-break 与重复戳错误码）；
  - 至少 1 段"缺失/零值"与 1 段"缺口"，二者在图上必须可区分（M4 打印黑白可辨的判据来源）。

## 无出处落库禁令

本题目不涉及法规/阈值类外部知识，无"待核对"条目。若后续里程碑引入参考算法出处（如 STL 原始论文、MAD 的 1.4826 系数来源），以文献引用形式挂 `plan/` 文档，不把数值散落到代码或报告里。

## 数据与仓库字节的一致性

- 一切快照（CSV/JSON/HTML）一律 LF、UTF-8 无 BOM，故 `.gitattributes` 的 `* text=auto eol=lf` 不会改变克隆后的字节，`manifest.json` 登记的 sha256 在任意克隆中成立。
- 若将来引入二进制或非 LF 快照，**必须**在 `.gitattributes` 标 `-text`（否则克隆时被归一化、sha256 失配，而 `git status` 看不出来）。
