# plan/02 架构与技术选型

## 1. 技术选型

| 决策 | 采纳 | 弃选项与弃因 |
| --- | --- | --- |
| 实现语言 | Python ≥3.8 **纯标准库**（`csv`/`json`/`math`/`hashlib`/`statistics` 等），零第三方依赖 | numpy（题面 M2 允许，但归约顺序是**实现细节**：`np.mean`/`np.sum` 的分块求和跨版本可变 → 跨语言逐位复算不成立；且零依赖让 clone 即用与 CI 首推即绿更稳，见 D6）；statsmodels/pyod/darts（D3 已弃）；Node 实现（Python 双解释器矩阵更稳，JS 只做镜像） |
| 检测算术的书写形态 | **跨语言可镜像的操作序列**：只用 `+ - * / floor ceil abs min max` 与比较；幂次展开为乘法；**禁一切超越函数**（`exp/log/pow/sin/cos/sqrt` 及统计库里的隐式调用），见 §3.2 | 直接用 numpy/statistics 的向量化归约（结果依赖库实现细节，浏览器镜像无从对齐） |
| 浏览器内复算（M3 硬门禁） | **手写 JavaScript 镜像**（`src/anomaly_atlas/mirror/zaa_mirror.js`），与 Python 内核同一份算法口径说明、同一操作序列；HTML 内联原始数据 + 指纹 | 用 Web Crypto `crypto.subtle`（file:// 下 secure context 行为跨浏览器不一致，且它是"调库"不是"镜像"）；纯 JS 自实现 SHA-256（采纳，见 §3.3） |
| 数值落盘形态 | **规范 JSON 只含整数与字符串**：所有浮点在哈希边界做整数定点化（scale = 10^`quant_decimals`，默认 6，半偶舍入） | 直接写浮点字面量（CPython `repr` 与 JS `Number#toString` 的最短往返表示在极端情形不保证同串；定点整数彻底消除该风险，见 D7） |
| HTML 渲染 | Python 侧 `string.Template` 拼装单文件 HTML；SVG 坐标与分箱在 Python 侧确定性计算后内嵌 | 浏览器侧算布局/分箱（计算语义散落两处，违背"数字由确定性代码单点产出"）；Chart 类库（外链，违背零 CDN） |
| 交付形态 | SKILL.md + 源码包（clone 即用）+ 单文件 HTML 产物 | wheel/exe（首期不承诺，见 plan/06 边界）；实时服务/监控（题面明确不做） |
| 测试框架 | pytest（唯一 dev extra） | unittest（断言写法冗长，方法论既有口径） |
| JS 侧验证通道 | `tools/mirror_parity.py` 用 **Node** 执行产物内嵌镜像并与构建指纹对账（CI 与开发机实跑；本机无 Node 时该通路显式报 `exit 4`，不静默跳过） | 只靠"人眼看浏览器徽章"（不可自动化、不可在 CI 复跑）；headless 浏览器依赖（本机自动化拉不起浏览器时无法作为门禁） |

## 3. 跨语言逐位复算策略（本题护城河的实现口径）

M3 要求"浏览器里用 JS 镜像重算出同一 `sha256`"。这件事在浮点上并不自动成立，必须靠三条硬纪律把不确定性挤出去。

### 3.1 算法口径单点定义

- 检测算法的**文字口径**（窗口、权重、迭代次数、比较符号、合并与排序键）只在 `data/README.md` §4 定义一次；Python 实现与 JS 镜像都是它的翻译，**谁都不准"顺手优化"**（例如把 `(1-w)*(1-w)` 写成 `pow`、把两点均值写成一次性求和）。
- 每个 Python 检测函数与 `zaa_mirror.js` 中的同名函数**逐语句对应**，函数头注释互相指名（`mirrors: detect.rolling_mad_z`）。

### 3.2 数值可镜像性纪律（K4）

| 允许 | 说明 |
| --- | --- |
| `+ - * /`、一元负号 | IEEE-754 双精度基本运算，Python 与 JS 逐位一致 |
| `floor ceil abs min max` | 语义完全一致 |
| 比较运算符、布尔逻辑、整数取模/整除（Python `//` vs JS `Math.floor(a/b)`，仅限非负操作数） | 在非负域内等价 |
| 常量乘法（如 MAD 的 `1.4826`） | 乘一个十进制常量，属基本运算 |

| 禁止 | 弃因 |
| --- | --- |
| `exp log pow sin cos tan atan2 hypot` | 超越函数由各语言 libm 实现，**结果不保证逐位相同**（V8 与 glibc/CRT 可差 1 ulp） |
| `**` / `Math.pow(x,2)` | 展开为 `x*x`；整数幂展开为连乘 |
| `np.mean/np.sum/np.dot/np.median`（若引入 numpy） | 归约顺序是实现细节；本项目零依赖，连该风险面都不引入 |
| `statistics.mean/median/pvariance` | 同上（其内部求和顺序不受我们控制），改用自写显式循环 |
| 哈希路径上的 `float → 字符串` | 由 §3.3 的整数定点化取代 |

**自证门**：`tests/test_no_transcendental.py` 对 `src/anomaly_atlas/` 与 `mirror/zaa_mirror.js` 做 AST/词法扫描（Python 用 `ast` 白名单，JS 用正则 + 显式豁免表），命中即红；配套**变异验证**（往检测路径塞一个 `math.exp` → 门必须红）。

**M3 落地**：镜像、嵌入契约与 Node 对账通道已落地并按上述纪律实跑（`verify` / `tools/mirror_parity.py`；逐位一致、篡改必红并定位到被篡改的 series，见 `plan/05` M3 状态列）。实施中发现一条与"（1−w²)² 不许写成 `pow`"同族的假绿：**指纹相等不是定点规则的正确性证据**——把镜像的半偶舍入边界挪动 5e-7，冻结数据的指纹对账照样全绿（没有分数落进那个口子）。因此定点规则另配一组**跨语言向量**（`mirror.FIXED_POINT_VECTORS`），由 Node 跑产物自带的镜像与其 Python 对应实现逐项对账。

### 3.3 规范 JSON 与哈希（数值形态）

- 哈希输入 = **规范 JSON 的字节序列**（`sort_keys=True`、`ensure_ascii=False`、`indent=2`、LF、结尾换行）。
- 规范 JSON **只允许出现字符串、整数、布尔、null 与这些值的数组/对象**——不允许浮点字面量。
- 浮点定点化：`q = 半偶舍入(x * 10^d)`（`d = quant_decimals`，默认 6），落盘为整数；需要展示十进制时由整数构造（`sign + q // 10^d + "." + 补零(q % 10^d)`），Python 与 JS 用同一整数算法，**任何一端都不经过浮点格式化**。
- 定点化同时吸收"1 ulp 级"的跨语言残差：只要两侧操作序列一致，`x` 逐位相同，定点化结果必然相同；即使出现极端分歧，`quant_decimals` 记录在 run-spec 里，可作为处置旋钮。
- sha256 取十六进制小写；异常集指纹、真值指纹、浏览器复算指纹**共用同一函数**。

### 3.4 SHA-256 由手写纯 JS 实现

浏览器端不能依赖 `crypto.subtle`（file:// 的 secure context 行为跨浏览器不一致，且题面要求"手写镜像"）。`zaa_mirror.js` 内实现紧凑 SHA-256（整数位运算，逐位可复算），并用**已知向量**自检（空串、`"abc"`、长于 55 字节与长于 64 字节的用例），Python 侧同一批向量由 `hashlib` 断言——两侧共享同一组测试向量。

## 4. 确定性策略（全项目单点纪律）

1. **禁随机、禁时钟**：检测/剖面/渲染代码路径不读系统时间、不用 `random`；HTML 内出现的"版本标识"必须是内容派生（对规范 JSON 取 sha256 前 N 位），不得是时间戳。
2. **禁迭代序入产物**：一切集合输出前显式排序（比较器含源行号索引 tie-break，K6），杜绝 dict/set 迭代序进入字节。
3. **序列化冻结（K2）**：JSON = `json.dumps(sort_keys=True, ensure_ascii=False, indent=2)` + LF + 结尾换行；HTML = LF + UTF-8 无 BOM。
4. **字节级双跑断言**：同输入两次运行 `profile`/`detect`/`render` 产物逐字节一致——`--check` 通路（生成器）+ 守门测试两层（冻结产物形态 + 重生成比对）。
5. **零外链硬断言**：`render` 出口常驻 `assert_no_external_resources(html)`（禁 `http://`、`https://`、协议相对 `//`、`<link>`、`<script src>`、`href=`、`src=`），非仅测试期验一次；同一出口还有 `assert_no_template_slots(html)`（产物不得含任何 `$`，D21i）。
6. **分位数口径**：线性插值，自实现单点定义（`data/README.md` §4.1 的"共同口径"与 `detect._quantile`），并注明 JS 镜像同法。

```
timebase ──▶ csvio ──▶ profile ──▶ canon（M1：规范 JSON + sha256 + 定点化原语）
                 └───▶ detect ──▶ episodes ──▶ canon（M2：build_anomaly_set，定点化 + 规范 JSON + sha256）

                              facts  ──▶ report ◀─────┘

tools/mirror_parity.py ──▶ 产物级复算对账（Node）+ 产物构建（write_view）
```

- `canon` 的 K2/K3 原语在 M1 即落地（D18a）：`profile`（剖面落盘）与生成器（真值哈希）都要用它，避免规范 JSON 与 sha256 出现第二、第三份实现。
- `layout` 只从 `canon`（定点化/展示串）与 `detect`（窗口径：`_median`/`robust_scale`/`_quantile`/`dominant_interval`）取口径，不重实现统计；`layout` 的输出**不含浮点**（见 `tests/test_layout.py::test_every_coordinate_is_an_integer`）。
- 呈现参数（`pad_rows` / `heat_bin_ms`）走 render 自己的 run-spec，**不进异常集指纹**（D22）。

- 依赖单向；`render` 只消费上游结论、零判定逻辑（不做检测、不改异常点）。
- **退出码契约**（骨架期即锁，锁进测试；退役进程见 plan/06 D8–D10/D23）：

| 退出码 | 含义 | 场景 |
| --- | --- | --- |
| 0 | 成功 | 各子命令正常完成 |
| 1 | 门禁/自检发现缺陷 | `selftest` 失败、数字白名单未命中（`check-report` / `render --narrative`）、复算 MISMATCH |

## 6. 反模式禁令（一票否决）

1. 模型手改异常点、新增未检测到的点 → 违规（题面 §1.1 模型禁区）。
2. 报告中出现未命中 `facts.json` 的数字，或引用档案外的 `episode_id`/行号 → 门禁失败（题面 M5；`check-report` exit 1 且**列全**，`render --narrative` 连产物都不写）。
3. `render` 从前端重算判决（除灵敏度滑杆这一显式通道，且其重算必须走同一 JS 内核）→ 违规。
4. 骨架期用 `return 0` / `return True` 空壳充当"已实现" → 违规（方法论「编排链空壳」族）。
5. 用 `not_enabled`/静默 skip 掩盖"没跑" → 违规：未启用分支必须显式 `not_enabled=true` + 原因 + 非零退出码。
